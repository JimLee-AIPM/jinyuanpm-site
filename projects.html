产品与项目经验

P01 / PROJECT · 阿里巴巴 · 千问C端事业群 · 2026.03 – 2026.09

千问 × 淘宝闪购 「一句话点外卖」 AI产品经理助理实习生 · badcase 归类 · 优化建议跟进 · 竞品横评

项目背景
千问 App 于 2026 年 1 月接入淘宝闪购与支付宝 AI 付，实现「一句话点外卖」的端内交易闭环。
项目内容
用户自然语言输入后识别外卖意图，调用闪购 Agent 查询商家商品、库存、实时价格与优惠，生成商品卡片，经支付宝 AI 付在对话内完成支付。
我的职责
以实习生身份参与链路迭代：整理归类 badcase 并输出优化建议，配合算法、工程团队跟进落地，承担「AI 点外卖」场景的竞品横评。
项目成果
整理 badcase 与优化建议 20 余条，跟进其中 3 项至上线，上线后完成回归确认；两类高频体验断点形成问题清单，供团队排优先级。
技术 / AI 能力
C 端办事 Agent意图识别Badcase 归类同指令竞品横评

P02 / PROJECT · 腾讯 · CSIG（云与智慧产业事业群） · 2025.03 – 2025.09

腾讯元器 智能体创作与分发平台 AI产品实习生 · 用户反馈归因 · 微信支付 MCP 走查 · 多智能体验收

项目背景
元器是腾讯基于混元大模型的智能体创作与分发平台，实习期间持续深耕公众号生态。
项目内容
平台先后接入微信支付 MCP、升级至 v1.0 并新增多智能体协作能力；公众号运营者授权后即可用历史文章搭建智能体。
我的职责
负责公众号智能体的用户反馈整理与问题归因；全职期间参与微信支付 MCP 的功能走查与 v1.0 多智能体协作模块的上线前验收。
项目成果
将「授权后文章列表显示不全」确认归为两类原因并提交问题单；管理员扫码卡点的反馈材料提交后，授权页提示得到优化。
技术 / AI 能力
公众号智能体微信支付 MCP多智能体协作上线前验收

P03 / PROJECT · 导师合作项目 · AI菁英创业班 · 2024.10 – 2025.03

灵搭 企业级智能体搭建平台 小组组长 · Agent 模块梳理 · 多 Agent 协作链路测试 · Text-to-Agent 走查

项目背景
校内导师个人与北京未来式智能（AutoAgents.ai）的合作项目。灵搭是基于自研 Multi-Agent 架构的企业级智能体搭建平台，面向电力、金融、制造等行业。
项目内容
五人学生小组由导师挑选组成，在导师工作室集中办公，使用导师分配的测试环境承担产品体验与反馈工作。
我的职责
任小组组长，负责 Agent 模块、多 Agent 协作与自然语言交互三部分的体验与测试。
项目成果
整理模块说明文档；输出十余条问题清单，分调度异常、汇总丢失、生成流程偏差三类；输出 Text-to-Agent 走查意见。

P04 / PROJECT · 个人独立开发 · 2026.10 – 2026.11

DeskTidy 一键收起桌面 Vibe Coding · Mac App Store 上架审核中

项目背景
干活时同时开着 ChatGPT、Claude、浏览器和飞书。窗口越堆越多，一切换就开始掉帧。
项目内容
原生 Mac 菜单栏应用，macOS 13 起可用。一键清理只隐藏、不关闭；支持按「工作场景」保留应用，并内置番茄钟。
我的职责
一个人全程独立完成：产品定义、交互把关、规则约束、与 AI 结对开发、验收测试到打包发布。
项目成果
源码在 GitHub 公开，完整版免费分发；已提交 Mac App Store，上架审核中。
